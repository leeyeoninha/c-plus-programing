## 빌드
Visual Studio에서 과제별로 프로젝트를 하나씩 만들어 빌드하면 됩니다.

- `common/CommissionEmployee.h` 와 `common/CommissionEmployee.cpp` 를 **모든 과제 프로젝트에 함께** 추가합니다.
- 과제 1·2·4·5는 헤더(.h)와 소스(.cpp)를 함께 추가하고, `main.cpp` 가 있는 경우 그것을 시작 파일로 둡니다.
- 과제 3은 `protected_version.cpp` 한 파일로 빌드합니다(기반 클래스를 안에 함께 정의).
- 이번 주 소스는 C++20 전용 기능을 쓰지 않으므로 기본 언어 표준으로 빌드됩니다.

페이지의 모든 실행 예시는 실제로 컴파일·실행한 출력입니다. 예시는 **정상 경로만** 싣습니다 — 예외·경계값 케이스는 학생이 직접 만들어 제출합니다.
