# 6주차 · C++ 10장 단항 연산자와 증가·감소 연산자 오버로딩

Deitel 「C++ How to Program」 10/e 학습 확인용 자료입니다.
학습 범위는 10장 10.6 단항 연산자 오버로딩 ~ 10.8 사례 연구: Date 클래스까지입니다.
강의자료의 [보충] 항목(C++20 삼방 비교 연산자 <=>)과 10.9 이후 내용(동적 메모리 관리,
Array 클래스 등)은 확인 범위에서 제외했습니다.

## 구성
- `index.html` — 배포용 단일 페이지
  - 01 이해도 점검 퀴즈 14문항
  - 02 코드 오류 찾기 6문항
  - 03 직접 구현해 보기 3과제 (난이도 중 2 · 상 1)
- `src/` — 실습과제 모범 답안 원본 소스
  - `task1_time_increment.cpp` (중) 전위·후위 ++ / --와 += 오버로딩 — Time 클래스
  - `task2_date_decrement_compare.cpp` (중) Date 클래스 확장 — 전위·후위 --와 관계 연산자 6개
  - `task3_date_arithmetic.cpp` (상) 날짜 계산기 — 이항 + / -와 >> 오버로딩

## 다루는 내용
단항 연산자 오버로딩(멤버 / 비멤버) · 전위·후위 ++ / -- 와 더미 int 매개변수 ·
전위는 참조, 후위는 값 반환 · += 와 연쇄 · Date 클래스 사례 연구
(helpIncrement, leapYear, endOfMonth, static const days 배열) ·
관계 연산자 짝 맞추기 · + 를 += 에 위임하기 · 비멤버 operator+ · >> 와 예외

## 빌드
Visual Studio에서 과제별로 소스 파일 하나씩 빈 프로젝트에 추가해 빌드하면 됩니다.
이번 주 소스는 C++20 전용 기능을 쓰지 않으므로 기본 언어 표준으로도 빌드됩니다.

페이지의 모든 실행 예시는 실제로 컴파일·실행한 출력입니다.
