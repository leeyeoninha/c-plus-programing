01

이론 확인 문제 — 4지선다 16문항

보기를 누르면 바로 정답 여부가 표시됩니다. 점수는 매기지 않습니다 — 틀린 문항의 해설을 읽고 넘어가세요.

Q1. 함수 void report(ostream& out) { out << "ok\n"; }가 있습니다. 다음 호출 중 컴파일되지 않는 것은?

①report(cout);
②report(cerr);
③report(clog);
④report(cin);

정답 및 해설 보기

정답 ④

cout·cerr·clog는 모두 ostream 객체이므로 ostream& 매개변수에 그대로 묶입니다. cin은 istream 객체입니다. istream과 ostream은 둘 다 basic_ios를 상속하는 형제 클래스일 뿐 서로의 파생 클래스가 아니므로, istream을 ostream&로 받을 수 없습니다. 기반 클래스 참조로 받는 함수는 그 클래스와 파생 클래스 객체만 받습니다(12장 다형성과 같은 규칙). cerr는 버퍼 없이 바로, clog는 버퍼에 모았다가 출력한다는 차이도 함께 기억하세요. 근거: 13.2.2~13.2.3 (p4~7)

Q2. 다음 세 줄의 출력으로 옳은 것은?

const char* word = "again";
cout << word << '\n';                         // (가)
cout << static_cast<const void*>(word)
     << '\n';                                 // (나)
cout << *word << '\n';                        // (다)
①(가) again · (나) 문자열이 저장된 주소 · (다) a
②(가) 문자열이 저장된 주소 · (나) again · (다) a
③(가) again · (나) again · (다) 문자열이 저장된 주소
④(가) again · (나) 문자열이 저장된 주소 · (다) again

정답 및 해설 보기

정답 ①

<<는 char *를 널 문자로 끝나는 C 문자열로 보고 내용을 출력합니다. 주소를 보려면 void *로 바꿔야 합니다. *word는 첫 문자 하나(char)이므로 a만 나옵니다. 주소값 자체는 실행할 때마다, 컴파일러마다 다르게 보입니다. 근거: 13.3.1 (p8~9)

Q3. 다음 코드의 출력은?

cout.put('C').put(43).put(43).put('\n');
①C4343
②C++
③C43 43
④컴파일 오류 — put은 연쇄 호출할 수 없다

정답 및 해설 보기

정답 ②

put은 문자 하나를 출력하고 같은 ostream의 참조를 돌려주므로 연쇄 호출이 됩니다. 정수 인자 43은 숫자로 출력되는 것이 아니라 ASCII 코드 43인 문자 +로 출력됩니다. 근거: 13.3.2 (p10)

Q4. 키보드로 Hello World를 입력하고 Enter를 눌렀습니다. 출력은?

char buf[6];
cin.get(buf, 6);
char c;
cin.get(c);
cout << '[' << buf << "][" << c << ']';
①[Hello][W]
②[Hello ][W]
③[Hello][ ]
④[Hello W][o]

정답 및 해설 보기

정답 ③

세 인자(여기서는 구분자 기본값 '\n')를 받는 get은 크기 제한보다 하나 적은 5문자 Hello를 읽고 끝에 널 문자를 넣습니다. 여섯 번째 문자인 공백은 스트림에 남아 있으므로 다음 get(c)가 공백을 읽습니다. get(char&)는 공백도 건너뛰지 않습니다. 근거: 13.4.1 (p12, p15)

Q5. 두 줄 abc, def를 입력했습니다. 출력은?

char a[10], b[10];
cin.get(a, 10);
cin.get(b, 10);
cout << '[' << a << "][" << b << "] " << cin.fail();
①[abc][def] 0
②[abc][] 1
③[abc][def] 1
④[abc][] 0

정답 및 해설 보기

정답 ②

get은 구분자 '\n'을 배열에 넣지 않고 스트림에 남깁니다. 그래서 두 번째 get은 첫 문자부터 구분자를 만나 한 글자도 읽지 못합니다. 아무것도 읽지 못한 get은 빈 문자열을 저장하고 failbit를 켭니다. 첫 번째를 getline으로 바꾸면 '\n'을 읽어서 버리므로 두 번째가 def를 읽습니다. 근거: 13.4.1 (p15, p18)

Q6. 2024abc를 입력했습니다. 출력은?

char c;
cin.get(c);
cin.putback(c);
cout << static_cast<char>(cin.peek());
cin.ignore(2);
int n;
cin >> n;
cout << ' ' << n;
①2 24
②0 24
③2 2024
④2 4

정답 및 해설 보기

정답 ①

get으로 읽은 2를 putback이 되돌려 놓았으므로 peek은 다시 2를 봅니다. peek은 문자를 꺼내지 않습니다. ignore(2)가 2와 0 두 문자를 버리고, >>는 24까지 읽은 뒤 a에서 멈춥니다. 근거: 13.4.2 (p21)

Q7. ABCDEFGH를 입력하고 Enter를 눌렀습니다. 출력은?

char buf[20];
cin.read(buf, 5);
cout << cin.gcount() << ' ';
cin.ignore(100, '\n');
cout << cin.gcount() << ' ';
cout.write(buf, 3);
①5 9 ABC
②5 4 ABCDE
③5 4 ABC
④5 5 ABC

정답 및 해설 보기

정답 ③

gcount()는 누적값이 아니라 마지막 입력 연산이 읽은 문자 수입니다. read가 5문자, 이어지는 ignore가 F G H와 '\n'까지 4문자를 읽었습니다. write(buf, 3)은 배열에서 정확히 3바이트만 출력합니다. read는 널 문자를 붙이지 않으므로 buf를 <<로 출력하면 안 됩니다. 근거: 13.5 (p22~23)

Q8. 다음 코드의 출력은?

int x = 255;
cout << hex << x << ' ' << x + 1 << ' '
     << dec << x << ' ' << setbase(8) << 8;
①ff 256 255 10
②ff 100 ff 10
③ff 100 255 8
④ff 100 255 10

정답 및 해설 보기

정답 ④

진법 설정은 sticky입니다. hex 뒤의 x + 1(256)도 16진수 100으로 나옵니다. dec으로 되돌린 뒤의 255는 10진수, setbase(8) 뒤의 8은 8진수 10입니다. setbase는 <iomanip>이 필요합니다. 근거: 13.6.1 (p25~27)

Q9. 다음 코드의 출력은?

double v = 1234.5678;
cout << setprecision(3) << v << ' ' << fixed << v;
①1234.568 1234.568
②1.23e+03 1234.568
③1234.568 1234.57
④1.23e+03 1234.57

정답 및 해설 보기

정답 ②

fixed도 scientific도 없으면 정밀도는 유효숫자 전체 개수입니다. 1234.5678을 유효숫자 3개로는 고정 표기로 나타낼 수 없어 지수 표기 1.23e+03이 됩니다. fixed를 켠 뒤에는 같은 정밀도 3이 소수점 아래 자리 수가 되어 1234.568(넷째 자리에서 반올림)이 됩니다. 정밀도는 sticky라 두 번째 출력에도 3이 남아 있습니다. 근거: 13.6.2 (p28~31), 13.7.1 (p43)

Q10. Programming을 입력했습니다. 출력은?

char word[6];
cin >> setw(6) >> word;
cout << setfill('.') << '[' << setw(7) << word
     << "][" << word << ']';
①[.Progra][Progra]
②[Progr..][Progr]
③[..Progr][Progr]
④[Programming][Programming]

정답 및 해설 보기

정답 ③

입력에서 setw(6)은 널 문자 자리를 남기고 5문자까지만 읽게 합니다(Progr). 출력에서 setw(7)은 기본 오른쪽 정렬이므로 모자란 두 칸을 채움 문자 .로 왼쪽에 채웁니다. 폭은 sticky가 아니어서 두 번째 word는 폭 없이 출력됩니다. 근거: 13.6.3 (p32~35), 13.7.3 (p50)

Q11. 다음 사용자 정의 조작자가 있습니다. 아래 네 줄 중 컴파일 오류가 나는 것은?

ostream& stars(ostream& out) { return out << "**"; }
①cout << stars << "Hi";
②cout << "Hi" << stars << stars;
③stars(cout) << "Hi";
④cout << stars() << "Hi";

정답 및 해설 보기

정답 ④

cout << stars는 함수를 호출하지 않고 함수 주소를 넘깁니다. ostream에는 ostream& (*)(ostream&) 타입을 받는 operator<<가 있어서 그 안에서 stars(cout)를 호출합니다. 반환형이 ostream&이므로 뒤로 연쇄할 수 있습니다. ③은 직접 호출한 것이라 문제없습니다. ④는 매개변수가 하나 필요한 함수를 인자 없이 호출했으므로 오류입니다. 그래서 함수형 조작자로는 추가 매개변수를 받을 수 없습니다(03 실습 문제 3에서 클래스로 해결합니다). 근거: 13.6.4 (p36~39)

Q12. 다음 코드의 출력은?

cout << 79.0 << ' ' << showpoint << 79.0 << ' '
     << fixed << setprecision(1) << 79.0;
①79 79.0000 79.0
②79.0 79.0000 79.0
③79 79.00000 79.0
④79 79.0000 79.0000

정답 및 해설 보기

정답 ①

기본 상태에서는 뒤따르는 0과 소수점을 생략해 79가 됩니다. showpoint는 소수점과 뒤따르는 0을 붙이되 자릿수는 정밀도가 정합니다. 기본 정밀도 6은 유효숫자 6개이므로 79.0000입니다. fixed와 setprecision(1) 뒤에는 소수 한 자리 79.0입니다. 근거: 13.7.1 (p43~45), 13.7.5 (p57)

Q13. 다음 코드의 출력은?

cout << showpos << internal << setfill('#')
     << setw(7) << 123 << ' '
     << left << setw(6) << -45 << '|';
①+123### -45###|
②###+123 -45###|
③+###123 -45###|
④+###123 ###-45|

정답 및 해설 보기

정답 ③

internal은 부호를 왼쪽, 숫자를 오른쪽에 두고 채움 문자를 가운데 넣습니다. showpos 때문에 양수 123에 +가 붙습니다. 이어서 left로 바꾸면 -45 뒤에 채움 문자가 붙습니다. 채움 문자 #는 sticky라 두 번째 필드에도 그대로 쓰입니다. 근거: 13.7.2 (p46~49), 13.7.3 (p50)

Q14. 다음 코드의 출력은?

cout << showbase << oct << 8 << ' ' << hex << 255 << ' '
     << uppercase << 255 << ' ' << dec << 255;
①010 0xff 0xFF 255
②010 0xff 0XFF 255
③8 0xff 0XFF 255
④010 0xff 0XFF 0XFF

정답 및 해설 보기

정답 ②

showbase는 8진수 앞에 0, 16진수 앞에 0x를 붙입니다. uppercase는 16진수 숫자 A~F뿐 아니라 접두사의 X도 대문자로 바꿉니다. 10진수에는 표시가 붙지 않습니다. 근거: 13.7.4 (p54~56), 13.7.6 (p60)

Q15. 12abc를 입력했습니다. 출력은?

int a = -1, b = -1;
cin >> a >> b;
cout << a << ' ' << cin.fail() << ' ';
cin.clear();
char c;
cin >> c;
cout << c;
①12 1 a
②12 0 a
③12 1 b
④0 1 1

정답 및 해설 보기

정답 ①

a는 12까지 읽고 a에서 멈춥니다. b는 첫 문자 a가 숫자가 아니어서 실패하고 failbit가 켜집니다. failbit는 잘못된 문자를 지우지 않으므로 a는 스트림에 그대로 남습니다. clear()로 상태만 되돌린 뒤 char로 읽으면 바로 그 a가 나옵니다. 근거: 13.8 (p65)

Q16. abc를 입력했습니다. 출력은?

int x;
cin >> x;
cout << boolalpha << !cin << ' ';
cin.clear();
cout << cin.good() << ' ';
cin.clear(ios::failbit);
cout << cin.fail() << ' ' << noboolalpha
     << static_cast<bool>(cin);
①true true false 0
②1 1 1 0
③true true false 1
④true true true 0

정답 및 해설 보기

정답 ④

!cin은 failbit나 badbit가 켜져 있으면 true입니다. 인자 없는 clear()는 goodbit로 되돌리므로 good()은 true입니다. clear(ios::failbit)는 failbit를 끄는 것이 아니라 상태를 인자로 준 값으로 설정하므로 failbit가 다시 켜집니다. boolalpha는 sticky라 noboolalpha 전까지 true/false로 나오고, 마지막 bool 변환(조건식 if (cin)과 같은 검사)은 0입니다. 근거: 13.7.7 (p62~64), 13.8 (p67~68)

02

진단 — 제공 코드에 변이 만들기

제공 코드는 두 벌입니다. A(input_diag.cpp)는 입력 함수와 복구, B(format_diag.cpp)는 서식 조작자와 오류 상태 함수(good eof fail bad rdstate clear operator! bool 변환)를 다룹니다. 진단 1~3은 A, 진단 4~7은 B를 바꿉니다.

진행 순서 — 아래 다섯 단계를 순서대로 진행하세요.

  1. A 기준선 — input_diag.cpp를 바꾸지 않고 실행하고, 파일 첫머리 주석의 다섯 줄을 차례로 입력하세요. 화면 전체를 기준선으로 적으세요.
  2. 진단 1~3 — A를 문항마다 한 곳만 바꿔 다시 실행하세요. 입력은 기준선과 같게 넣되, 프로그램이 입력을 기다리지 않고 지나가면 기다리는 곳에서만 넣으세요. 기준선과 달라진 줄을 찾아 기록표의 네 칸을 채우고, 다음 문항 전에 코드를 원래대로 되돌리세요.
  3. B 기준선과 기준선 상태표 — format_diag.cpp를 바꾸지 않고 실행하세요. count:에 7, x, 12를 차례로 넣고, 마지막 count:에서는 Ctrl+Z를 누르고 Enter를 치세요(콘솔에서 입력의 끝 EOF를 보내는 방법입니다). 화면 전체를 기준선으로 적은 뒤, 바로 아래 기준선 상태표를 채우세요.
  4. 진단 4~7 — 2단계와 같은 방법으로 B를 바꿔 실행하고 기록표를 채우세요. 상태 줄은 기준선 상태표와 한 칸씩 비교하세요.
  5. 진단 8 — 기준선 상태표의 read x 줄과 eof 줄을 근거로 글로 답하세요.

기준선 상태표 — 3단계에서 채웁니다. B의 기준선 출력 가운데 start, read 7, read x, clear, read 12, eof로 시작하는 여섯 줄의 값을 그대로 옮기세요. 마지막 칸에는 그 값이 나온 이유를 한 줄로 적으세요. 바로 앞에서 어떤 연산이 실행되었고, 그 결과 어떤 비트가 켜지거나 꺼졌는지를 쓰면 됩니다.

// 13.4 get / getline / peek / putback / ignore, 13.5 read / write / gcount, 13.8 오류 상태
//
// 실행하면 아래 다섯 줄을 차례로 입력하세요.
//   Kim 3000
//   Development
//   A-17
//   x9
//   29
#include <iostream>
using namespace std;

// 스트림 상태 함수 네 개를 한 줄로 보여 준다
void showState(const char* tag)
{
    cout << "  [" << tag << "] good=" << cin.good() << " eof=" << cin.eof()
         << " fail=" << cin.fail() << " bad=" << cin.bad() << '\n';
}

// 다음 문자를 꺼내지 않고(peek) 보여 준다
void showNext()
{
    int c = cin.peek();
    if (c == EOF)
        cout << "next=EOF";
    else if (c == '\n')
        cout << "next='\\n'";
    else
        cout << "next='" << static_cast<char>(c) << "'";
}

int main()
{
    // ---- 1) >> 연산자 : 공백에서 멈춘다 ----
    char name[10];
    int pay = 0;
    cout << "name pay: ";
    cin >> name >> pay;                           // 입력 1
    cout << "name=[" << name << "] pay=" << pay << '\n';
    cin.ignore(100, '\n');                        // (A) 줄 끝의 '\n'까지 버린다
    showState("line1");

    // ---- 2) get 3인자 : n-1개까지, 구분자는 남긴다 ----
    char dept[8];
    cout << "dept: ";
    cin.get(dept, 8);                             // (B) 입력 2
    cout << "dept=[" << dept << "] ";
    showNext();
    cout << '\n';
    cin.ignore(100, '\n');                        // (C)
    cout << "ignored " << cin.gcount() << " chars\n";
    showState("line2");

    // ---- 3) get(char&) / peek / putback / read / write ----
    char grade = ' ';
    cout << "grade: ";
    cin.get(grade);                               // 입력 3
    cout << "grade=" << grade << ' ';
    showNext();
    cout << '\n';
    cin.putback(grade);                           // (D) 읽은 문자를 되돌린다
    char code[4] = {};
    cin.read(code, 4);                            // (E) 널 문자를 붙이지 않는다
    cout << "read " << cin.gcount() << ": ";
    cout.write(code, cin.gcount());              // 읽은 만큼만 출력
    cout << '\n';
    cin.ignore(100, '\n');
    showState("line3");

    // ---- 4) 서식 오류와 복구 ----
    int age = -1;
    cout << "age: ";
    cin >> age;                                   // 입력 4
    cout << "age=" << age << '\n';
    showState("bad age");
    cin.clear();                                  // (F) 상태를 goodbit로
    cin.ignore(100, '\n');                        // (G) 남은 문자 버리기
    cout << "age again: ";
    cin >> age;                                   // 입력 5
    cout << "age=" << age << '\n';
    showState("end");
    return 0;
}

// format_diag.cpp — 12주차 02 진단 · 제공 코드 B (서식·상태 계열)
// 13.6 조작자, 13.7 서식 상태, 13.8 오류 상태(good/eof/fail/bad/rdstate/clear/operator!/operator bool)
//
// 실행하면 count: 에 차례로 입력하세요.
//   7
//   x
//   12
//   Ctrl+Z 를 누르고 Enter   (입력의 끝 = EOF)
#include <iostream>
#include <iomanip>
using namespace std;

struct Row
{
    const char* name;
    int id;
    double pay;
    bool fulltime;
};

// 상태 함수를 모두 호출해 본다. rdstate()의 정수값은 컴파일러마다 다르므로
// 비트 하나를 골라 0/1로 확인한다.
void showState(const char* tag)
{
    cout << left << setw(8) << tag << right
         << " good=" << cin.good() << " eof=" << cin.eof()
         << " fail=" << cin.fail() << " bad=" << cin.bad()
         << " rd&fail=" << ((cin.rdstate() & ios::failbit) != 0)
         << " !cin=" << !cin
         << " bool=" << static_cast<bool>(cin) << '\n';
}

int main()
{
    const Row rows[3] = {
        { "Kim", 161, 3000.0, true },
        { "Lee", 2748, 2512.345, false },
        { "Park", 31, 4100.5, true }
    };

    // ---- 1) 서식 표 ----
    cout << left << setw(6) << "name" << right << setw(9) << "id"
         << setw(11) << "pay" << setw(7) << "full" << '\n';
    cout << setfill('-') << setw(33) << "" << '\n';
    cout << setfill(' ');                                   // (A) 채움 문자 되돌리기
    cout << fixed << setprecision(2) << boolalpha;          // (B)
    for (const Row& r : rows) {
        cout << left << setw(6) << r.name << right
             << hex << showbase << uppercase << setw(9) << r.id
             << dec << noshowbase                           // (C) 진법 되돌리기
             << setw(11) << r.pay << setw(7) << r.fulltime << '\n';
    }
    cout << noboolalpha << '\n';                            // (D)

    // ---- 2) 오류 상태 확인 ----
    int n = -1;
    showState("start");

    cout << "count: ";
    cin >> n;                                               // 입력 7
    cout << "n=" << n << '\n';
    showState("read 7");

    cout << "count: ";
    cin >> n;                                               // 입력 x
    cout << "n=" << n << '\n';
    showState("read x");

    cin.clear();                                            // (E) goodbit로 초기화
    showState("clear");
    cin.ignore(100, '\n');                                  // (F) 남은 x 버리기

    cout << "count: ";
    cin >> n;                                               // 입력 12
    cout << "n=" << n << '\n';
    showState("read 12");

    cout << "count: ";
    cin >> n;                                               // Ctrl+Z
    cout << "n=" << n << '\n';
    showState("eof");
    return 0;
}

진단 8 — 설명형: 같은 실패인데 왜 n이 다른가

B의 기준선에서 x를 넣었을 때는 n=0, Ctrl+Z를 넣었을 때는 n=12가 나왔습니다. 두 경우 모두 fail=1입니다. 다음 세 가지를 설명하세요.

  1. 두 경우에 n의 값이 다른 이유
  2. 마지막 지점에서 eof와 fail이 함께 1인 이유
  3. 같은 입력(7, x, 12, Ctrl+Z)에 while (cin >> n) cout << n << '\n';을 쓰면 몇 개의 수가 출력되는지와 그 이유
모범 답안 보기

모범 답안 (1) x를 넣은 경우는 공백을 건너뛴 뒤 문자가 있었으므로 수로 바꾸는 단계까지 가서 실패했고, 실패한 변환은 변수에 0을 넣습니다. Ctrl+Z를 넣은 경우는 공백을 건너뛰다 바로 입력의 끝에 닿아 변환을 시도하지도 못했으므로 n이 바뀌지 않아 직전 값 12가 남습니다. (2) 입력의 끝에 닿아 eofbit가 켜졌고, 요청한 정수를 하나도 읽지 못했으므로 failbit도 켜집니다. 그래서 eof()만으로 루프를 끝내면 마지막 실패를 놓치기 쉽고, 읽기가 성공했는지는 fail()이나 스트림의 bool 변환으로 확인합니다. (3) 7 하나만 출력됩니다. while (cin >> n)의 조건은 >>가 돌려준 cin을 bool로 바꾼 값(교재의 operator void *, 지금은 explicit operator bool)이고, failbit나 badbit가 켜지면 false입니다. x에서 failbit가 켜지는 순간 루프가 끝나므로 12는 읽지 않습니다. 참고로 rdstate()의 정수값은 컴파일러마다 다르므로(교재 p67의 표와 다른 구현이 있습니다) 코드 B처럼 rdstate() & ios::failbit로 비트를 골라 확인하거나 fail()·eof()를 씁니다.

문제 3 [상] — 조작자를 클래스로 직접 만들기

교재 13.6.4의 조작자는 ostream& 이름(ostream&) 함수입니다. 이 방식은 cout << 이름처럼 매개변수 없이만 쓸 수 있습니다(이론 11번). 이 문제에서는 조작자를 클래스로 만들어 매개변수가 없는 조작자와 있는 조작자를 모두 만들고, 리포트 출력에 써 봅니다.

요구 사항

  1. Manip.h(#pragma once)에 추상 클래스 OutManip을 두세요. 순수 가상 함수 void apply(ostream& out) const 하나를 갖습니다.
  2. operator<<(ostream& out, const OutManip& m)은 하나만 만드세요. m.apply(out)을 부르고 out을 돌려줍니다.
  3. 매개변수 없는 조작자 클래스 두 개를 OutManip에서 파생하세요. Sep은 " | "를 출력하고, ResetFormat은 서식을 처음 상태(10진수·skipws, 채움 문자 공백, 정밀도 6, 폭 0)로 되돌립니다. 객체를 하나씩 만들어 두고 이름으로 씁니다: inline const Sep sep{};, inline const ResetFormat resetfmt{};
  4. 매개변수 있는 조작자 클래스 세 개를 OutManip에서 파생하세요. 생성자 인자가 조작자의 매개변수이고, 기본 인자로 일부를 생략할 수 있게 합니다.
  5. Line(char ch = '-', int count = 40)은 ch를 count개 출력하고 줄을 바꿉니다. HexId(int id, int digits = 4)는 0X00A1처럼 출력합니다. Money(double value, int width = 12, int places = 2)는 오른쪽 정렬·고정 소수점으로 출력합니다.
  6. HexId와 Money는 바꾼 서식 상태를 apply가 끝나기 전에 되돌리세요. 조작자를 쓴 뒤에도 cout의 상태가 그대로여야 합니다.
  7. 입력 조작자 클래스 Expect(char ch)를 만드세요. cin >> Expect(':')는 공백을 건너뛴 뒤 다음 문자가 ':'이면 꺼내고, 아니면 꺼내지 않고 cin.clear(cin.rdstate() | ios::failbit)로 failbit를 켭니다.
  8. 비교용으로 교재 방식의 함수형 조작자 endLine('\n' + flush)도 Manip.h에 두세요.
  9. main은 아래 사용 예의 [1]~[3]을 출력하고, [4]에서 id:pay 줄을 0이 나올 때까지 읽어 [5] 리포트를 만드세요. 실패한 줄은 cerr에 메시지를 출력하고 clear()와 ignore로 버립니다.

개념 보충 cout << endLine이 동작하는 것은 ostream이 ostream& (*)(ostream&) 타입을 받는 operator<<를 미리 갖고 있기 때문이고, 그래서 함수형 조작자는 스트림 외의 인자를 받을 수 없습니다. 매개변수가 필요하면 값을 멤버로 저장하는 객체를 만들고, 그 객체를 받는 operator<<를 정의합니다. setw(6)·setprecision(2) 같은 표준 조작자도 같은 원리로 동작합니다. 공통 기반 OutManip과 가상 함수 apply()를 두면 조작자를 몇 개 추가하든 operator<<는 하나로 충분합니다. 입력 조작자가 기대한 문자를 찾지 못했을 때 failbit를 켜는 것은 >>가 숫자 자리에서 문자를 만났을 때와 같은 규칙을 따르게 하려는 것이며, 그래서 호출하는 쪽은 if (!(cin >> ...)) 한 번으로 실패를 검사할 수 있습니다.
