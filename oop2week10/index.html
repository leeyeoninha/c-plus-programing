제공 코드 A — 진단 1~5 공통

이 코드를 그대로 컴파일·실행하면 정상 동작합니다. 먼저 아래 기준선을 적어 두세요.

#include <iostream>
#include <string>

class Animal {
public:
    Animal(const std::string& name) : name_(name) {}
    virtual ~Animal() { std::cout << "[소멸] Animal(" << name_ << ")" << std::endl; }
    virtual void makeSound() const { std::cout << "Some sound" << std::endl; }
    const std::string& getName() const { return name_; }
private:
    std::string name_;
};

class Dog : public Animal {
public:
    Dog(const std::string& name) : Animal(name), ball_(new int[10]) {}
    ~Dog() {
        std::cout << "[소멸] Dog(" << getName() << ")" << std::endl;
        delete[] ball_;
    }
    void makeSound() const { std::cout << "Woof!" << std::endl; }
    void fetch() const { std::cout << "공을 물어 옵니다." << std::endl; }
private:
    int* ball_;
};

class Cat : public Animal {
public:
    Cat(const std::string& name) : Animal(name) {}
    ~Cat() { std::cout << "[소멸] Cat(" << getName() << ")" << std::endl; }
    void makeSound() const { std::cout << "Meow!" << std::endl; }
};

void makeAnimalSound(const Animal& animal) { animal.makeSound(); }

int main() {
    Dog dog("바둑이");
    Cat cat("나비");

    Animal* p = &dog;
    p->makeSound();

    makeAnimalSound(cat);

    Animal* q = new Dog("순돌이");
    delete q;

    return 0;
}

기준선 출력: Woof! / Meow! / [소멸] Dog(순돌이) / [소멸] Animal(순돌이) / [소멸] Cat(나비) / [소멸] Animal(나비) / [소멸] Dog(바둑이) / [소멸] Animal(바둑이)

진단 1

기반 포인터의 접근 범위

바꾸기: p->makeSound(); 아래에 p->fetch(); 한 줄 추가 → 컴파일

정답 및 해설 보기

증상: 컴파일 오류 — Animal에 fetch가 없다.
원인: 멤버는 핸들 타입으로 찾는다. 다형성은 가상 함수 호출에만 작용하고, 파생 전용 멤버는 기반에 선언이 없다.
수정: Dog* d = dynamic_cast<Dog*>(p); if (d != nullptr) d->fetch(); — 또는 기반에 virtual fetch()를 올린다.

진단 2

기반 객체를 파생 포인터로

바꾸기: main에 아래 두 줄 추가

Animal animal("기본");
Dog* r = &animal;
정답 및 해설 보기

증상: 컴파일 오류 — Animal*을 Dog*로 변환할 수 없다.
원인: 기반 객체는 파생이 아니다(파생 부분이 없다). 반대 방향(기반 포인터 ← 파생 객체)만 안전하다.
수정: Dog dog2("새끼"); Dog* r = &dog2; — 기반 객체를 파생으로 쓰려는 시도 자체가 설계 오류다.

진단 3

protected·private 상속은 is-a가 아니다

바꾸기: ① class Dog : public Animal → class Dog : private Animal ② main에 makeAnimalSound(dog); 한 줄 추가 ③ 확인한 뒤 protected Animal로도 바꿔 같은 실험을 반복(상속 지정자 두 종류를 한 번에 본다)

정답 및 해설 보기

증상: 한 원인으로 오류 세 개 — Animal* p = &dog;, makeAnimalSound(dog);, 그리고 파생 내부가 아닌 곳에서의 기반 변환. 문구는 셋 다 "Animal이 접근할 수 없는 기반이다".
원인: private 상속은 is-a가 아니다. "Dog은 Animal이다"가 성립하지 않으므로 Animal*·Animal& 자리에 넣을 수 없다. 기반으로의 변환은 파생 클래스 내부에서만 허용된다.
수정: public Animal로 되돌린다 — 다형적으로 쓰려면 public 상속이어야 한다. protected도 결과가 같다(셋 다 "inaccessible base").

진단 4

virtual을 지우면 다형성이 꺼진다

바꾸기: Animal의 virtual void makeSound() const에서 virtual만 삭제 (다른 줄은 그대로)

정답 및 해설 보기

증상: 출력이 Some sound / Some sound — 포인터 호출도, 참조 호출도 둘 다 기반 버전이다. 경고 0.
원인: 두 함수는 시그니처가 같지만 기반에 virtual이 없어 vtable 슬롯이 만들어지지 않았다. 파생의 함수는 재정의가 아니라 이름을 가린 별개의 함수다.
수정: virtual을 되돌린다 — 기반 한 곳에만 붙이면 파생도 자동으로 가상이다.
확인: 같은 코드에서 dog.makeSound();(객체 이름)를 추가하면 Woof!가 나온다. 정적 바인딩이 기반 함수를 부르는 게 아니라는 증거다.

진단 5

가상 소멸자

바꾸기: virtual ~Animal()에서 virtual만 삭제

class Animal {
public:
    enum AnimalType { CAT, DOG, BIRD };
    Animal(AnimalType type) : type_(type) {}
    AnimalType getType() const { return type_; }
private:
    AnimalType type_;
};
class Cat  : public Animal { public: Cat()  : Animal(CAT)  {} void makeSound() const { std::cout << "Meow!"  << std::endl; } };
class Dog  : public Animal { public: Dog()  : Animal(DOG)  {} void makeSound() const { std::cout << "Woof!"  << std::endl; } };
class Bird : public Animal { public: Bird() : Animal(BIRD) {} void makeSound() const { std::cout << "Tweet!" << std::endl; } };

void makeAnimalSound(const Animal& animal) {
    switch (animal.getType()) {
    case Animal::CAT:  static_cast<const Cat&>(animal).makeSound();  break;
    case Animal::DOG:  static_cast<const Dog&>(animal).makeSound();  break;
    case Animal::BIRD: static_cast<const Bird&>(animal).makeSound(); break;
    default: std::cout << "Unknown animal sound!" << std::endl;
    }
}
int main() {
    Cat cat; Dog dog; Bird bird;
    makeAnimalSound(cat); makeAnimalSound(dog); makeAnimalSound(bird);
}
정답 및 해설 보기

증상: delete q;에서 [소멸] Animal(순돌이)만 찍히고 [소멸] Dog(순돌이)가 사라진다. Dog가 잡은 new int[10]은 남는다.
원인: delete는 포인터의 정적 타입(Animal)으로 처리된다. 소멸자가 virtual이 아니면 실제 타입을 볼 통로(vtable)를 쓰지 않는다.
수정: virtual ~Animal() = default;
확인: 되돌린 뒤 같은 줄이 두 줄(Dog → Animal)로 돌아오는지 본다.

심화 — "표준이 정의하지 않는다"를 수치로 확인 (같은 실험 파일에 추가)
⑴ sizeof(Animal)과 sizeof(Dog)를 출력한다 — 40 / 48
⑵ Dog 생성자에서 new int[10]을 잡고, 아직 정리되지 않은 버퍼 수를 세는 정적 카운터를 둔다(생성 +1, 소멸 −1)
⑶ Animal* p = new Dog("바둑이"); delete p; 실행 → 소멸 로그·카운터·delete 전후를 출력(실행 결과: [소멸] Animal 한 줄, 카운터 1)
⑷ virtual ~Animal()을 붙여 다시 실행 → [소멸] Dog → [소멸] Animal, 카운터 0
⑸ (여유가 있으면) 두 클래스에 static void operator delete(void*, std::size_t)를 정의해 delete가 넘기는 크기를 출력 — 기반 포인터 delete는 40(실제 할당은 48), 파생 포인터 delete는 48
정리: 소멸자를 고르지 못한 것(파생 자원 미정리)과 해제 크기가 어긋난 것(40 vs 48)이 같은 원인이다 — 동적 타입을 알 통로(vtable)를 쓰지 않았기 때문. 올바른 동작을 정의할 방법이 없어 표준이 UB로 남긴다.

제공 코드 B — 진단 6 전용

이 코드를 그대로 컴파일·실행하면 정상 동작합니다.

class Animal {
public:
    enum AnimalType { CAT, DOG, BIRD };
    Animal(AnimalType type) : type_(type) {}
    AnimalType getType() const { return type_; }
private:
    AnimalType type_;
};
class Cat  : public Animal { public: Cat()  : Animal(CAT)  {} void makeSound() const { std::cout << "Meow!"  << std::endl; } };
class Dog  : public Animal { public: Dog()  : Animal(DOG)  {} void makeSound() const { std::cout << "Woof!"  << std::endl; } };
class Bird : public Animal { public: Bird() : Animal(BIRD) {} void makeSound() const { std::cout << "Tweet!" << std::endl; } };

void makeAnimalSound(const Animal& animal) {
    switch (animal.getType()) {
    case Animal::CAT:  static_cast<const Cat&>(animal).makeSound();  break;
    case Animal::DOG:  static_cast<const Dog&>(animal).makeSound();  break;
    case Animal::BIRD: static_cast<const Bird&>(animal).makeSound(); break;
    default: std::cout << "Unknown animal sound!" << std::endl;
    }
}
int main() {
    Cat cat; Dog dog; Bird bird;
    makeAnimalSound(cat); makeAnimalSound(dog); makeAnimalSound(bird);
}

진단 7

static_cast와 dynamic_cast, 무엇이 다른가

바꾸기: main에서 p->makeSound(); 아래에 네 줄 추가

Dog* d1 = dynamic_cast<Dog*>(p);   // 실제 객체는 Dog
Cat* c1 = dynamic_cast<Cat*>(p);
Dog* d2 = static_cast<Dog*>(p);
Cat* c2 = static_cast<Cat*>(p);
std::cout << "dynamic_cast<Dog*> "  << (d1 != nullptr ? "성공" : "nullptr") << std::endl;
std::cout << "static_cast<Dog*>  "  << (d2 != nullptr ? "성공" : "nullptr") << std::endl;
std::cout << "dynamic_cast<Cat*> "  << (c1 != nullptr ? "성공" : "nullptr") << std::endl;
std::cout << "static_cast<Cat*>  "  << (c2 != nullptr ? "성공" : "nullptr") << std::endl;
--- 캐스팅 실험 ---
dynamic_cast<Dog*> 성공
static_cast<Dog*>  성공
dynamic_cast<Cat*> nullptr
static_cast<Cat*>  성공
정답 및 해설 보기

증상(실행 결과)
→ 표로 정리
| 실제 객체 | 캐스트 | 결과 |
| Dog | dynamic_cast<Dog*> | 성공 |
| Dog | static_cast<Dog*> | 성공 |
| Dog | dynamic_cast<Cat*> | nullptr |
| Dog | static_cast<Cat*> | 포인터를 돌려줌 |

원인: dynamic_cast는 실행 중에 실제 타입을 확인하고, 실패하면 nullptr로 알려 준다. static_cast는 확인하지 않고 컴파일러에게 "믿어라"고 말하는 것이라 실패를 알릴 방법이 없다.
포인트(학생이 놓치는 지점): 일치하는 조합에서는 둘의 결과가 똑같다. 차이는 일치하지 않을 때만 드러나므로, 실험에 반드시 불일치 조합을 넣어야 한다.
수정: 확인이 필요하면 dynamic_cast + nullptr 검사. 타입이 확실할 때만 static_cast.
추가 관찰: c2->makeSound()를 실행하면 컴파일·실행은 되지만 Cat 객체가 아닌 것을 Cat으로 취급한 것이라 정의되지 않은 동작입니다. 실행하지 말고, 왜 위험한지 두 줄로 적습니다(멤버를 읽으면 엉뚱한 메모리를 읽고, 가상 호출이면 vtable을 잘못 짚는다).

진단 8

dynamic_cast는 다형 타입에서만 동작한다

바꾸기: 제공 코드 A에서 Animal의 virtual을 전부 지우고(~Animal, makeSound 둘 다), main에 Cat* c = dynamic_cast<Cat*>(p); 한 줄 추가

정답 및 해설 보기

증상: 컴파일 오류 — 대표적인 문구가 "source type is not polymorphic"입니다(컴파일러마다 표현은 다르지만 뜻은 같습니다).
원인: dynamic_cast는 실행 중 타입 정보(vtable)를 읽어 판정한다. 가상 함수가 하나도 없으면 그 정보 자체가 없어 판정할 방법이 없다 → 언어가 컴파일 단계에서 막는다.
이어서 확인할 것 — 같은 줄을 static_cast<Cat*>(p);로 바꾸면 컴파일된다. 실행 결과: static_cast<Cat*> 성공이 찍힙니다. 즉
- dynamic_cast — 타입 정보가 필요하고, 없으면 컴파일 오류
- static_cast — 타입 정보가 필요 없고, 없어도 조용히 통과

이 대비가 두 캐스트의 성격을 가장 선명하게 보여 줍니다. 검사를 해 주는 쪽은 조건이 까다롭고, 검사를 안 하는 쪽은 조건이 없다.

설계 카드(제출)
① 기반 Shape에 둘 것 — 모든 도형이 공통으로 가진 것
② 그중 virtual로 둘 것 — 도형마다 답이 달라지는 것
③ 파생마다 새로 가지는 것 — 면적 계산에 필요한 값
④ main이 알아야 할 것 — 파생 타입의 이름이 main에 나오면 안 된다는 조건에서 출발
요구사항
① Shape 기반 + Circle, Rectangle, Triangle
② 각 도형은 print()로 이름: 면적을 출력한다(면적은 소수 둘째 자리까지)
③ main은 Shape* shapes[3]에 세 도형의 주소를 담고, 반복문 하나로 전부 출력한다
④ 같은 반복문에서 총 면적과 가장 넓은 도형의 이름을 구한다
⑤ 조건문에 if (도형종류 == 원) 같은 타입 분기를 쓰지 않는다 — 필요한 정보는 전부 가상 함수가 돌려준다
⑥ 확장 시험: Trapezoid(사다리꼴, (윗변+아랫변)*높이/2)를 추가하고 main은 한 글자도 고치지 않고 네 줄이 나오는지 확인한다. 설계 카드 ②가 맞았다면 0줄, 틀렸다면 고친 줄 수를 적는다
⑦ 이번 과제는 스택 객체만 쓰므로 소멸자는 virtual이 아니어도 된다. 다만 기반 포인터로 delete할 수 있는 설계로 바꾼다면 무엇을 고쳐야 하는지 한 줄로 적는다(과제3에서 실제로 확인)

// 과제2 [중] — 도형 계층 설계 (모범답안, Linux 검증용: #pragma comment 는 주석)
#include <iostream>
#include <iomanip>
#include <string>

class Shape {
public:
    virtual ~Shape() = default;
    virtual std::string name() const { return "도형"; }
    virtual double area() const { return 0.0; }
    virtual void print() const {
        std::cout << name() << ": " << std::fixed << std::setprecision(2) << area() << std::endl;
    }
};

class Circle : public Shape {
public:
    Circle(double r) : r_(r) {}
    std::string name() const { return "원"; }
    double area() const { return 3.14159 * r_ * r_; }
private:
    double r_;
};

class Rectangle : public Shape {
public:
    Rectangle(double w, double h) : w_(w), h_(h) {}
    std::string name() const { return "직사각형"; }
    double area() const { return w_ * h_; }
private:
    double w_, h_;
};

class Triangle : public Shape {
public:
    Triangle(double base, double height) : base_(base), height_(height) {}
    std::string name() const { return "삼각형"; }
    double area() const { return base_ * height_ / 2.0; }
private:
    double base_, height_;
};

int main() {
    Circle circle(3.0);
    Rectangle rect(4.0, 5.0);
    Triangle tri(6.0, 2.0);

    Shape* shapes[3] = { &circle, &rect, &tri };

    double total = 0.0;
    const Shape* widest = shapes[0];
    for (int i = 0; i < 3; ++i) {
        shapes[i]->print();
        total += shapes[i]->area();
        if (shapes[i]->area() > widest->area()) {
            widest = shapes[i];
        }
    }
    std::cout << "총 면적: " << std::fixed << std::setprecision(2) << total << std::endl;
    std::cout << "가장 넓은 도형: " << widest->name() << std::endl;

    return 0;
}

// 과제3 [상] — 급여 시스템 (모범답안). 과제1의 EmployeeLib.lib 를 그대로 쓴다.
// VS: 프로젝트 폴더에 Employee.h / EmployeeLib.lib 복사 + #pragma comment(lib, "EmployeeLib.lib")
#include <iostream>
#include <iomanip>
#include <string>
#include "Employee.h"

class SalariedEmployee : public Employee {
public:
    SalariedEmployee(const std::string& name, double monthly)
        : Employee(name), monthly_(monthly) {
        std::cout << "[생성] SalariedEmployee(" << getName() << ")" << std::endl;
    }
    ~SalariedEmployee() { std::cout << "[소멸] SalariedEmployee(" << getName() << ")" << std::endl; }
    double earnings() const { return monthly_; }
    void print() const {
        Employee::print();
        std::cout << "  월급: " << monthly_ << std::endl;
    }
private:
    double monthly_;
};

class HourlyEmployee : public Employee {
public:
    HourlyEmployee(const std::string& name, double wage, double hours)
        : Employee(name), wage_(wage), hours_(hours) {
        std::cout << "[생성] HourlyEmployee(" << getName() << ")" << std::endl;
    }
    ~HourlyEmployee() { std::cout << "[소멸] HourlyEmployee(" << getName() << ")" << std::endl; }
    double earnings() const {
        if (hours_ <= 40.0) return wage_ * hours_;
        return wage_ * 40.0 + wage_ * 1.5 * (hours_ - 40.0);
    }
    bool isOvertime() const { return hours_ > 40.0; }
    void print() const {
        Employee::print();
        std::cout << "  시급: " << wage_ << ", 시간: " << hours_ << std::endl;
    }
private:
    double wage_, hours_;
};

class CommissionEmployee : public Employee {
public:
    CommissionEmployee(const std::string& name, double sales, double rate)
        : Employee(name), sales_(sales), rate_(rate) {
        std::cout << "[생성] CommissionEmployee(" << getName() << ")" << std::endl;
    }
    ~CommissionEmployee() { std::cout << "[소멸] CommissionEmployee(" << getName() << ")" << std::endl; }
    double earnings() const { return sales_ * rate_; }
    void print() const {
        Employee::print();
        std::cout << "  판매액: " << sales_ << ", 수수료율: " << rate_ << std::endl;
    }
private:
    double sales_, rate_;
};

int main() {
    Employee** staff = new Employee*[4];
    staff[0] = new SalariedEmployee("Kim", 3200.0);
    staff[1] = new HourlyEmployee("Lee", 20.0, 45.0);
    staff[2] = new CommissionEmployee("Park", 20000.0, 0.05);
    staff[3] = new SalariedEmployee("Choi", 2800.0);

    std::cout << "\n--- 명단 ---" << std::endl;
    double total = 0.0;
    for (int i = 0; i < 4; ++i) {
        staff[i]->print();
        total += staff[i]->earnings();
    }
    std::cout << "총 급여: " << std::fixed << std::setprecision(2) << total << std::endl;

    std::cout << "\n--- 시간외 근무자 ---" << std::endl;
    for (int i = 0; i < 4; ++i) {
        HourlyEmployee* h = dynamic_cast<HourlyEmployee*>(staff[i]);
        if (h != nullptr && h->isOvertime()) {
            std::cout << h->getName() << std::endl;
        }
    }

    std::cout << "\n--- 정리 ---" << std::endl;
    for (int i = 3; i >= 0; --i) delete staff[i];
    delete[] staff;
    return 0;
}
