과제 1 · [난이도 하] struct Time — 멤버 직접 접근이 위험한 이유

교재의 struct Time(멤버: hour, minute, second)을 그대로 선언하고, 입력받은 시각을 24시간 형식과 12시간 형식으로 출력해 보세요. 그 뒤 검증 없이 잘못된 값을 대입해 구조체의 한계를 눈으로 확인합니다.

조건: 멤버는 hour, minute, second 세 개 · printUniversal(const Time &)은 setfill('0'), setw(2)로 00:00:00 형식 출력 · printStandard(const Time &)은 0시와 12시를 12로, 12시 미만은 AM, 이상은 PM으로 출력 · 두 함수 모두 const 레퍼런스 매개변수 · 마지막에 hour = 29, minute = 73을 대입해 다시 출력

which is 6:30:00 PM standard time.

[검증 없음] 잘못된 값 29시 73분을 그대로 대입합니다.
Time with invalid values: 29:73:00

// 과제 1 (하) · struct Time — 멤버 직접 접근의 위험
#include <iostream>
#include <iomanip>
using namespace std;

struct Time {           // 구조체 태그
    int hour;           // 0-23
    int minute;         // 0-59
    int second;         // 0-59
};

void printUniversal(const Time &t) {
    cout << setfill('0') << setw(2) << t.hour << ":"
         << setw(2) << t.minute << ":" << setw(2) << t.second;
}
void printStandard(const Time &t) {
    cout << ((t.hour == 0 || t.hour == 12) ? 12 : t.hour % 12)
         << ":" << setfill('0') << setw(2) << t.minute
         << ":" << setw(2) << t.second
         << (t.hour < 12 ? " AM" : " PM");
}

int main() {
    Time dinnerTime;
    cout << "시, 분, 초를 입력하세요: ";
    cin >> dinnerTime.hour >> dinnerTime.minute >> dinnerTime.second;

    cout << "Dinner will be held at ";
    printUniversal(dinnerTime);
    cout << " universal time,\nwhich is ";
    printStandard(dinnerTime);
    cout << " standard time.\n";

    cout << "\n[검증 없음] 잘못된 값 29시 73분을 그대로 대입합니다.\n";
    dinnerTime.hour = 29;
    dinnerTime.minute = 73;
    cout << "Time with invalid values: ";
    printUniversal(dinnerTime);
    cout << endl;
    return 0;
}

노란색으로 표시된 부분이 학생이 입력하는 값입니다. 마지막 출력에서 29시 73분이 아무 저항 없이 저장되는 것에 주목하세요 — 멤버가 public이면 객체 스스로 잘못된 상태를 막을 방법이 없습니다. 과제 2에서 이 문제를 class로 해결합니다.

과제 2 · [난이도 중] class Time — 캡슐화와 유효성 검사

과제 1의 구조체를 클래스로 바꿉니다. hour, minute, second를 private으로 감추고, 기본 생성자가 0으로 초기화하며, setTime()이 범위를 벗어난 값을 0으로 만들어 잘못된 상태를 원천 차단하도록 만들어 보세요.

조건: 멤버 변수는 private, 생성자·setTime·printUniversal·printStandard는 public · 생성자에서 hour = minute = second = 0;으로 일관된 초기 상태 보장 · setTime은 삼항 연산자로 시 0~23, 분 0~59, 초 0~59를 검사하고 벗어나면 해당 멤버만 0 · 멤버 함수는 클래스 밖에서 void Time::setTime(int, int, int) 형태로 정의 · 출력 함수는 const 멤버 함수

// 과제 2 (중) · class Time — 캡슐화와 유효성 검사
#include <iostream>
#include <iomanip>
using namespace std;

class Time {
public:
    Time();                               // 생성자
    void setTime(int, int, int);          // 유효성 검사 포함
    void printUniversal() const;
    void printStandard() const;
private:
    int hour;    // 0-23
    int minute;  // 0-59
    int second;  // 0-59
};

Time::Time() { hour = minute = second = 0; }

void Time::setTime(int h, int m, int s) {
    hour   = (h >= 0 && h < 24) ? h : 0;
    minute = (m >= 0 && m < 60) ? m : 0;
    second = (s >= 0 && s < 60) ? s : 0;
}
void Time::printUniversal() const {
    cout << setfill('0') << setw(2) << hour << ":"
         << setw(2) << minute << ":" << setw(2) << second;
}
void Time::printStandard() const {
    cout << ((hour == 0 || hour == 12) ? 12 : hour % 12)
         << ":" << setfill('0') << setw(2) << minute
         << ":" << setw(2) << second
         << (hour < 12 ? " AM" : " PM");
}

int main() {
    Time t;
    cout << "The initial universal time is ";
    t.printUniversal();
    cout << "\nThe initial standard time is ";
    t.printStandard();

    int h, m, s;
    cout << "\n\n시, 분, 초를 입력하세요: ";
    cin >> h >> m >> s;
    t.setTime(h, m, s);

    cout << "Universal time after setTime is ";
    t.printUniversal();
    cout << "\nStandard time after setTime is ";
    t.printStandard();
    cout << endl;
    return 0;
}

실행 예시 ③이 핵심입니다. 시(10)와 초(30)는 살아 있고 범위를 벗어난 분만 0이 되었습니다 — 검사를 멤버별로 따로 하고 있기 때문입니다. 과제 1과 달리 이제 객체 외부에서는 절대로 잘못된 시각을 만들 수 없습니다.

과제 3 · [난이도 중] 객체 이름 · 레퍼런스 · 포인터로 멤버 접근하기

교재는 접근 연산자를 보여주기 위해 멤버 x를 public으로 두고 「IN FUTURE EXAMPLES WE AVOID PUBLIC DATA!」라고 경고합니다. 이 과제에서는 x를 private으로 되돌리고 get/set 함수를 경유해 같은 실험을 다시 해 봅니다.

조건: class Count의 x는 private, setX(int) / getX() const / print() const는 public · main에서 객체 counter, 포인터 counterPtr, 레퍼런스 counterRef를 각각 선언 · 세 핸들로 각각 1, 2, 3을 설정하고 그때마다 출력 · 마지막에 세 핸들로 값을 다시 읽어 같은 객체임을 확인 · (*counterPtr).getX() 형태도 함께 출력

실행 예시 — 입력 없음

Assign 1 to x and print using the object's name: 1
Assign 2 to x and print using a reference: 2
Assign 3 to x and print using a pointer: 3

세 핸들이 같은 객체를 가리키는지 확인
counter.getX()      = 3
counterRef.getX()   = 3
counterPtr->getX()  = 3
(*counterPtr).getX()= 3

채점 포인트 (5점) · 포인터·레퍼런스 선언과 초기화 1 · 점(.)과 화살표(->)의 올바른 사용 2 · (*p).x에 괄호가 필요한 이유 설명 1 · 세 핸들이 동일 객체의 별칭임을 출력으로 입증 1

모범 답안 보기 
// 과제 3 (중) · 객체 이름 / 레퍼런스 / 포인터로 멤버 접근하기
#include <iostream>
using namespace std;

class Count {
public:
    void setX(int _x) { x = _x; }   // set 함수
    int  getX() const { return x; } // get 함수
    void print() const { cout << x << endl; }
private:
    int x = 0;                      // 기본 private
};

int main() {
    Count counter;
    Count *counterPtr = &counter;   // 포인터
    Count &counterRef = counter;    // 레퍼런스

    cout << "Assign 1 to x and print using the object's name: ";
    counter.setX(1);
    counter.print();

    cout << "Assign 2 to x and print using a reference: ";
    counterRef.setX(2);
    counterRef.print();

    cout << "Assign 3 to x and print using a pointer: ";
    counterPtr->setX(3);
    counterPtr->print();

    cout << "\n세 핸들이 같은 객체를 가리키는지 확인\n";
    cout << "counter.getX()      = " << counter.getX() << endl;
    cout << "counterRef.getX()   = " << counterRef.getX() << endl;
    cout << "counterPtr->getX()  = " << counterPtr->getX() << endl;
    cout << "(*counterPtr).getX()= " << (*counterPtr).getX() << endl;
    return 0;
}

마지막 네 줄이 모두 3인 것이 이 과제의 결론입니다. 객체 이름, 레퍼런스, 포인터는 서로 다른 세 개의 객체가 아니라 같은 객체를 가리키는 세 개의 핸들입니다. counterPtr->getX()와 (*counterPtr).getX()는 완전히 같은 표현이며, *가 .보다 우선순위가 낮으므로 후자에서 괄호를 빼면 컴파일되지 않습니다.

과제 4 · [난이도 중] 생성자와 소멸자의 호출 순서

생성·소멸 시 메시지를 출력하는 CreateAndDestroy 클래스를 만들어, 전역 객체 · 자동 지역 객체 · static 지역 객체의 생성과 소멸 시점을 직접 눈으로 확인해 보세요.

조건: 생성자 CreateAndDestroy(int _id, string _message)가 「Object N constructor runs」와 메시지를 출력 · 소멸자가 「Object N destructor runs」와 메시지를 출력 · 객체 배치는 1번 main 밖 전역 / 2번 main의 자동 지역 / 3번 main의 static 지역 / 4번 main 후반부의 자동 지역 / 5·7번 create() 함수의 자동 지역 / 6번 create() 함수의 static 지역 · main이 create()를 호출한 뒤 다시 자기 코드를 실행하도록 구성 · 출력만 보고 순서를 설명할 수 있어야 함

실행 예시 — 입력 없음 (전체 출력)

MAIN FUNCTION: EXECUTION BEGINS
Object 2   constructor runs   (local automatic in main)

Object 7   constructor runs   (local automatic in create)

Object 5   destructor runs    (local automatic in create)

채점 포인트 (7점) · 생성자·소멸자 메시지 출력 1 · 요구된 7개 객체의 저장 기간 배치 2 · 자동 지역 객체의 역순 소멸 1 · static은 한 번만 생성되고 main 종료 후 소멸함을 출력으로 입증 2 · 출력 순서에 대한 설명 서술 1

모범 답안 보기 
// 과제 4 (중) · 생성자와 소멸자의 호출 순서
#include <iostream>
#include <string>
using namespace std;

class CreateAndDestroy {
public:
    CreateAndDestroy(int _id, string _message) {
        objectID = _id;
        message  = _message;
        cout << "Object " << objectID << "   constructor runs   "
             << message << endl;
    }
    ~CreateAndDestroy() {
        cout << "Object " << objectID << "   destructor runs    "
             << message << endl;
    }
private:
    int objectID;
    string message;
};

void create();                                  // 프로토타입

CreateAndDestroy first(1, "(global before main)");   // 전역 객체

int main() {
    cout << "\nMAIN FUNCTION: EXECUTION BEGINS" << endl;
    CreateAndDestroy second(2, "(local automatic in main)");
    static CreateAndDestroy third(3, "(local static in main)");

    create();                                   // 다른 함수 호출

    cout << "\nMAIN FUNCTION: EXECUTION RESUMES" << endl;
    CreateAndDestroy fourth(4, "(local automatic in main)");
    cout << "\nMAIN FUNCTION: EXECUTION ENDS" << endl;
    return 0;
}

void create() {
    cout << "\nCREATE FUNCTION: EXECUTION BEGINS" << endl;
    CreateAndDestroy fifth(5, "(local automatic in create)");
    static CreateAndDestroy sixth(6, "(local static in create)");
    CreateAndDestroy seventh(7, "(local automatic in create)");
    cout << "\nCREATE FUNCTION: EXECUTION ENDS" << endl;
}

읽는 법: 전역 1번이 main보다 먼저 생성됩니다 → create()의 자동 지역 7번, 5번은 함수가 끝나며 생성의 역순으로 소멸하지만 6번 static은 살아남습니다 → main이 끝나며 자동 지역 4번, 2번이 역순 소멸 → 그 뒤 static 6번, 3번이 소멸 → 가장 마지막에 전역 1번이 소멸합니다. abort()로 종료하면 이 소멸자들은 하나도 호출되지 않습니다.

// time2.h — 인터페이스

// time2.h — class Time 선언(인터페이스)
// 멤버 함수 정의는 time2.cpp에 있습니다.
#ifndef TIME2_H          // 헤더 중복 포함 방지
#define TIME2_H

class Time {
public:
    Time(int = 0, int = 0, int = 0);   // 기본 인자를 가진 생성자
    ~Time();                           // 소멸자
    void setTime(int, int, int);       // 유효성 검사 후 설정
    void printUniversal() const;       // 24시간 형식 출력
    void printStandard() const;        // 12시간 형식 출력
private:
    int hour;    // 0-23
    int minute;  // 0-59
    int second;  // 0-59
};

#endif

// time2.cpp — 구현

// time2.cpp — class Time의 멤버 함수 정의(구현)
#include <iostream>
#include <iomanip>
#include "time2.h"
using namespace std;

// 기본 인자를 가진 생성자: setTime을 재사용해 유효성 검사까지 수행
Time::Time(int h, int m, int s) {
    setTime(h, m, s);
    cout << "[생성] ";
    printUniversal();
    cout << " 객체가 만들어졌습니다." << endl;
}

Time::~Time() {
    cout << "[소멸] ";
    printUniversal();
    cout << " 객체가 소멸됩니다." << endl;
}

void Time::setTime(int h, int m, int s) {
    hour   = (h >= 0 && h < 24) ? h : 0;
    minute = (m >= 0 && m < 60) ? m : 0;
    second = (s >= 0 && s < 60) ? s : 0;
}

void Time::printUniversal() const {
    cout << setfill('0') << setw(2) << hour << ":"
         << setw(2) << minute << ":" << setw(2) << second;
}

void Time::printStandard() const {
    cout << ((hour == 0 || hour == 12) ? 12 : hour % 12)
         << ":" << setfill('0') << setw(2) << minute
         << ":" << setw(2) << second
         << (hour < 12 ? " AM" : " PM");
}

// main.cpp — Time 클래스 사용(구현을 몰라도 헤더만 보고 사용)
// 컴파일: g++ -std=c++17 main.cpp time2.cpp -o app
#include <iostream>
#include "time2.h"
using namespace std;

int main() {
    cout << "--- 기본 인자 생성자 4가지 호출 ---" << endl;
    Time t1;                  // 인자 0개 → 00:00:00
    Time t2(2);               // 시만 지정 → 02:00:00
    Time t3(21, 34);          // 시, 분   → 21:34:00
    Time t4(12, 25, 42);      // 전부 지정 → 12:25:42

    cout << "\n--- 잘못된 값으로 생성 ---" << endl;
    Time t5(27, 74, 99);      // 모두 범위 밖 → 00:00:00

    cout << "\n--- 각 객체 출력 (24시간 / 12시간) ---" << endl;
    Time *list[5] = { &t1, &t2, &t3, &t4, &t5 };
    for (int i = 0; i < 5; ++i) {
        cout << "t" << (i + 1) << " : ";
        list[i]->printUniversal();
        cout << "  |  ";
        list[i]->printStandard();
        cout << endl;
    }

    cout << "\n--- setTime으로 값 변경 ---" << endl;
    t1.setTime(13, 27, 6);
    cout << "t1 변경 후 : ";
    t1.printUniversal();
    cout << "  |  ";
    t1.printStandard();
    cout << endl;

    cout << "\n--- main 종료(소멸자는 생성의 역순) ---" << endl;
    return 0;
}

소멸 출력에서 두 가지를 확인하세요. 첫째, t5(00:00:00)가 가장 먼저 소멸하고 t1이 가장 나중에 소멸합니다 — 생성의 역순입니다. 둘째, t1은 생성 시각 00:00:00이 아니라 setTime으로 바뀐 13:27:06을 출력합니다 — 소멸자는 소멸 시점의 상태를 보고 있습니다.
