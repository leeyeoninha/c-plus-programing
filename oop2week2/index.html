과제 1 · 포인터 연산 — 피보나치 수열 출력

「배열의 전체 크기를 입력하세요: _」를 출력하고 숫자를 입력받습니다. 입력받은 크기만큼 피보나치 수열을 정적 배열에 채운 뒤, 「몇 번째 숫자마다 출력할까요?:_」에 입력받은 간격만큼 건너뛰며 값을 출력해 보세요.

조건: new/delete(동적 메모리 할당) 사용 금지 · 배열 원소는 *(포인터 + i) 형태의 포인터 연산으로 접근 · 배열 최대 크기 50 (초과 시 50으로 제한) · 피보나치 수열 값의 범위를 고려해 자료형 선택

예) 크기 30, 3번째마다 출력 → 2, 8, 34, 144, 610, 2584, 10946, 46368, 196418, 832040

모범 답안 보기 
#include <iostream>
using namespace std;

int main() {
    int size, interval;

    cout << "배열의 전체 크기를 입력하세요:_";
    cin >> size;
    if (size <= 1) size = 1;
    if (size > 50) size = 50;

    long long fibo[50];          // 값 범위 고려(long long)
    fibo[0] = 1;
    if (size > 1) fibo[1] = 1;
    for (int i = 2; i < size; ++i) {
        fibo[i] = fibo[i-1] + fibo[i-2];
    }

    cout << "몇 번째 숫자마다 출력할까요?:_";
    cin >> interval;

    for (int i = interval - 1; i < size; i += interval) {
        cout << *(fibo + i) << ", ";   // 포인터 연산으로 접근
    }
    cout << endl;
    return 0;
}

배열 이름 fibo는 첫 번째 원소의 주소이므로 *(fibo + i)와 fibo[i]는 완전히 같은 표현입니다.

과제 2 · 구조체 + 함수 매개변수 — Person 정적 배열과 check_age()

교재의 Person 구조체(멤버: name, age, height, weight)를 그대로 사용합니다. 미리 준비한 10명의 정보 배열에서 입력받은 크기(1~10, 초과 시 10)만큼 구조체 배열에 순서대로 대입하고, check_age() 함수를 호출해 나이가 25 이상인 사람의 정보를 모두 출력해 보세요.

조건: new/delete 사용 금지 · 구조체 배열은 정적 배열로 선언 · check_age(Person *_adult, int _count)는 포인터 매개변수로 전달받아 . 연산자로 멤버에 접근

모범 답안 보기 
#include <iostream>
using namespace std;

struct Person {
    string name;
    int age;
    float height;
    float weight;
};

void check_age(Person *_adult, int _count) {
    for (int i = 0; i < _count; i++) {
        if (_adult[i].age >= 25) {
            cout << "name : " << _adult[i].name << endl;
            cout << "age : " << _adult[i].age << endl;
            cout << "height : " << _adult[i].height << endl;
            cout << "weight : " << _adult[i].weight << endl;
            cout << endl;
        }
    }
}

int main() {
    string name_info[10] = { "Brain", "Jessica", "James", "Eric", "John",
                             "Tom", "Tomy", "Alice", "Bob", "Carol" };
    int age_info[10]  = { 24, 22, 30, 28, 35, 40, 25, 27, 32, 29 };
    float height_info[10] = { 180, 165, 170, 172, 168, 175, 169, 181, 163, 177 };
    float weight_info[10] = { 70, 55, 65, 68, 62, 75, 57, 73, 60, 80 };

    int size;
    cout << "배열의 전체 크기를 입력하세요:_";
    cin >> size;
    if (size <= 0) size = 1;
    if (size > 10) size = 10;

    Person adult[10];                    // 정적 배열
    for (int i = 0; i < size; ++i) {
        adult[i].name   = name_info[i];
        adult[i].age    = age_info[i];
        adult[i].height = height_info[i];
        adult[i].weight = weight_info[i];
    }

    check_age(adult, size);              // 배열의 시작 주소 전달
    return 0;
}
과제 3 · static — 고유 번호 발급 함수 만들기

호출될 때마다 1부터 순차적으로 증가하는 고유 번호(아이디)를 발급하는 함수를 static 지역 변수로 구현해 보세요. main()에서 10회 반복 호출하고, 마지막에 「총 N개의 Person이 처리되었습니다.」를 출력합니다.

조건: 고유 번호 카운터는 함수 내부의 정적 지역 변수(static)로 선언 · 전역 변수 사용 금지 · static은 처음 한 번만 초기화되고 호출 간 값이 유지된다는 점을 활용

모범 답안 보기 
#include <iostream>
using namespace std;

int getNewID() {
    static int ID = 0;      // 정적 지역 변수: 첫 호출에 한 번만 초기화
    return ++ID;
}

int main() {
    int lastID = 0;
    for (int i = 0; i < 10; ++i) {
        lastID = getNewID();
        cout << "ID: " << lastID << endl;
    }
    cout << "총 " << lastID << "개의 Person이 처리되었습니다." << endl;
    return 0;
}

일반 지역 변수라면 호출할 때마다 0으로 다시 초기화되지만, static 지역 변수는 프로그램 시작 시 한 번만 생성·초기화되어 값이 누적됩니다.

과제 4 · 레퍼런스 — swap과 구조체 나이 증가 함수

① 두 정수 값을 바꾸는 swap() 함수를 레퍼런스 매개변수로 구현해 a, b가 실제로 교환되는지 확인하세요. ② Person &_p 형태의 레퍼런스 매개변수를 받아 나이를 1 증가시키는 grow_older() 함수를 만들고 호출해 보세요.

조건: new/delete 사용 금지 · 일반 값 매개변수(call by value)로는 원본이 바뀌지 않는 이유까지 설명할 수 있어야 함

모범 답안 보기 
#include <iostream>
using namespace std;

struct Person {
    string name;
    int age;
};

void swap(int &ref_a, int &ref_b) {   // 레퍼런스 매개변수 = 원본의 별칭
    int temp = ref_a;
    ref_a = ref_b;
    ref_b = temp;
}

void grow_older(Person &_p) {         // 원본 구조체를 직접 수정
    _p.age++;
}

int main() {
    int a = 5, b = 10;
    swap(a, b);
    cout << "a : " << a << " b : " << b << endl;   // a : 10 b : 5

    Person adult = { "Brain", 24 };
    grow_older(adult);
    cout << adult.name << " " << adult.age << endl;  // Brain 25
    return 0;
}
