# 11주차 · 추상 클래스와 스트림

C++ How to Program 10/e · **12장 12.5 ~ 12.6 (추상 클래스·급여 시스템)** · **13장 1 ~ 14쪽 (스트림 입출력 첫 부분)**

## 구성

| 파트 | 내용 |
| 01 이론 | 4지선다 16문항 — 보기를 고르면 정답 여부가 바로 표시되고 해설이 열립니다(점수 없음) |
| 02 진단 | **제공 코드 + 변이 실험 8문항** — 코드에 변이를 직접 만들어 증상을 기록합니다(6번만 설명형) |
| 03 실습 | **문제 1개, 3단계** — 턴제 전투 게임의 유닛 계층을 직접 설계합니다 |

## 02 진단 하는 법

1. `src/diagnosis/employee_diag.cpp`(진단 1~5)와 `src/diagnosis/stream_diag.cpp`(진단 7·8)를 그대로 빌드·실행해 **기준선 출력**을 적습니다.
2. 문항의 "바꾸기"대로 **한 곳만** 바꿔 다시 빌드·실행합니다.
3. 표에 네 칸을 채웁니다 — **바꾼 줄 / 증상 / 원인 / 수정**.
4. 되돌려서 원상 복구까지 확인합니다. 2·4·8번은 화면에 오류가 뜨지 않으므로 **기준선과 비교**해 무엇이 달라졌는지 적는 것이 핵심입니다.

진단 6은 실행하지 않고, 왜 `cin.get()`의 반환값을 `char`에 담으면 안 되는지 글로 답합니다.

## 03 실습

주제는 **턴제 전투 게임**입니다. 유닛의 종류마다 공격 계산과 표시가 다른데, 전투를 진행하는 쪽은 유닛이 몇 종류인지 몰라도 돌아가야 합니다.

- **단계 1** — 설계 카드를 채우고, `src/task1/Unit.h`의 빈 자리(`virtual`, `= 0`, 소멸자)를 직접 결정해 추상 기반 클래스와 파생 두 개를 만듭니다.
- **단계 2** — `src/task2/main.cpp`의 예시 전투 루프를 그대로 쓰거나 바꿔서, 기반 포인터만으로 3라운드를 돌립니다. 네 번째 유닛을 추가할 때 루프를 고치지 않아야 합니다.
- **단계 3** — 표준 입력으로 유닛을 구성하고, `printReport(team, ostream&)`로 리포트를 출력합니다. 체력이 0 이하인 줄은 `cerr`로 경고하고 건너뜁니다.

모범 답안은 `src/task1/solution/`, `src/task2/`, `src/task3/`에 있습니다. 먼저 직접 작성한 뒤 비교하세요.

### 입력 형식 (단계 3)

```
W Conan 100 12        ← 월급제가 아니라 전사: 이름, 체력, 공격력
A Legolas 80 11 6     ← 궁수: 이름, 체력, 공격력, 민첩
M Gandalf 50 15 20    ← 마법사: 이름, 체력, 공격력, 마나
```

입력의 끝은 Visual Studio 콘솔에서 **Ctrl+Z**, 그 뒤 Enter입니다.

## 빌드 환경

- **Visual Studio** (C++ 데스크톱 개발 워크로드), 헤더 가드는 `#pragma once`.
- 표준은 **C++20 이상**을 권장합니다(프로젝트 속성 → C/C++ → 언어 → C++ 언어 표준).
- **프로그램 출력은 모두 영문입니다.** 콘솔 인코딩 때문에 한글이 깨지는 것을 피하려고 예제 코드의 `cout`·`cerr` 문자열에 한글을 쓰지 않았습니다.
- 소스 **주석**은 한글입니다. Visual Studio에서 `C4819` 경고가 나오면 파일을 **UTF-8(BOM)**으로 저장하거나 프로젝트 속성 → C/C++ → 명령줄에 `/utf-8`을 추가하세요.
