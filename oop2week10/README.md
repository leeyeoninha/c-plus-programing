| 02 진단 | **제공 코드 + 변이 실험 8문항** — 코드에 오류를 직접 만들어 증상을 기록합니다 |

## 02 진단 하는 법

1. `src/diagnosis/base_animal.cpp`(진단 1~5), `src/diagnosis/base_switch.cpp`(진단 6)를 그대로 빌드·실행해 **기준선 출력**을 적습니다.
2. 문항의 "바꾸기"대로 **한 줄만** 바꿔 다시 빌드·실행합니다.
3. 표에 4칸을 채웁니다 — **바꾼 줄 / 증상 / 원인 / 수정**.
4. **되돌려서 원상 복구**까지 확인합니다. 4·5·6·7번은 화면에 오류가 뜨지 않으므로 기준선과 비교해 무엇이 달라졌는지 적는 것이 핵심입니다.

## 03 실습

- **과제1 [하]** `Employee.h` + `Employee.cpp`를 **정적 라이브러리**로 빌드 → 새 콘솔 프로젝트에 헤더와 `.lib`만 넣고 파생 클래스를 작성합니다. 링크가 되는 이유와, `.lib`를 빼면 왜 링크 오류가 나는지 확인합니다.
- **과제2 [중]** 도형 계층을 **설계 카드 4칸**부터 씁니다. main에 타입 분기를 쓰지 않고, 새 도형을 추가할 때 main을 고치지 않는 구조를 만듭니다.
- **과제3 [상]** 과제1의 라이브러리를 그대로 다시 씁니다 — 파생 3종, 기반 포인터 배열, 총액, `dynamic_cast`, 가상 소멸자.

## 빌드 환경

- **Visual Studio** (C++ 데스크톱 개발 워크로드). 헤더 가드는 `#pragma once`.
- 표준은 **C++20 이상**을 권장합니다(프로젝트 속성 → C/C++ → 언어 → C++ 언어 표준).
- 과제1의 정적 라이브러리는 **Windows 데스크톱 → 정적 라이브러리** 프로젝트로 만들고, 만든 `.lib`와 헤더를 콘솔 프로젝트 폴더에 복사한 뒤 `#pragma comment(lib, "EmployeeLib.lib")` 한 줄로 링크합니다. 링커가 찾지 못하면 프로젝트 속성 → 링커 → 일반 → 추가 라이브러리 디렉터리에 폴더를 추가하세요.
