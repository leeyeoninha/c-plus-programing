## 02 토론·검증 하는 법 (2인 1조)

1. **역할** — 학생 1, 학생 2를 정합니다. 홀수 문항은 학생 1이 조작자·학생 2가 질문자, 짝수 문항은 반대입니다.
2. **기준선** — A와 B를 바꾸지 않고 한 번씩 실행해 화면을 함께 적습니다.
3. **바꾸기** — 조작자가 한 곳만 바꿉니다. 아직 실행하지 않습니다.
4. **실행 전 질문** — 질문자가 질문 카드를 묻고, 조작자의 예측과 이유를 기록표에 적습니다.
5. **실행과 비교** — 실행해 예측과 다른 줄을 찾습니다.
6. **실행 후 토론** — 카드의 실행 후 질문과 직접 만든 질문(예측·이유·변형·연결)으로 토론하고, 원인을 한 문장으로 합의해 적습니다.
7. **되돌리기** — 코드를 되돌리고 역할을 바꿉니다. 토론 2는 토론 1에서 늘어난 `clients.txt`를 그대로 둔 채 시작합니다.

## 03 실습

- **문제 1 [하] 순차 파일 만들기와 읽기** — `w`(새로 쓰기)·`a`(덧붙이기)를 골라 `clients.txt`를 열고, `계좌번호 이름 잔액`을 Ctrl+Z까지 입력받아 쓴 뒤 다시 읽어 표와 합계를 출력합니다. 시작 파일 `src/task1/main.cpp`의 TODO를 채웁니다.
- **문제 2 [중] 신용 조회 프로그램 확장** — 강의 슬라이드 19~26쪽의 신용 조회 프로그램을 바탕으로 요청마다 `clear()` + `seekg(0)`으로 파일을 다시 읽습니다. 잔액 0·음수·양수 목록과 계좌 찾기, 13장 방식 입력 검증, 슬라이드 23쪽 조건(`&&` → `||`) 수정. 실행 폴더에 `clients.txt`가 필요합니다(문제 1의 결과 또는 `src/task2/clients.txt`).
- **문제 3 [상] 인하항공 예약과 파일 저장** — `Seat`·`Schedule`·`AirlineBook` 클래스로 좌석 8개 × 비행편 3개(07·12·17시)의 예약·취소·보기를 만들고, 예약 상태를 `booking.txt`에 `시각 좌석 이름` 형식으로 저장합니다. 시작할 때 불러오고, 바뀔 때마다 파일 전체를 다시 씁니다(14.5).

## 빌드 환경

- Visual Studio, C++20 (`/std:c++20`). 헤더 가드는 `#pragma once`.
- 프로그램 출력은 영문(ASCII)만 씁니다. 주석은 한글입니다. 한글 주석이 깨지면 프로젝트 속성 → C/C++ → 명령줄에 `/utf-8`을 추가하세요.
- 파일마다 `main`이 있으므로 프로젝트 하나에 한 프로그램씩 넣어 빌드하세요.
- **파일 위치** — 프로그램이 만들고 읽는 파일(`clients.txt`, `accounts.txt`, `booking.txt`)은 실행 폴더에 생깁니다. Visual Studio에서 디버그 실행(F5)하면 실행 폴더는 프로젝트 폴더(`.vcxproj`가 있는 폴더)입니다. 문제 2의 `clients.txt`도 이 폴더에 두세요.
- 콘솔에서 입력의 끝(EOF)은 줄 맨 앞에서 Ctrl+Z를 누르고 Enter입니다.
